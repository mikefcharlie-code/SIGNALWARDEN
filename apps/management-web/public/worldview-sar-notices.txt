This application uses the latter notice for reduced-resolution provider-generated browse imagery, followed by "provider browse image and metadata retrieved from ASF DAAC". Access distinction: public catalog searches and reduced-resolution browse previews require no embedded login or API key. Full scientific product downloads from ASF require a free NASA Earthdata Login account and separate authorized tooling; this application does not download full products. Provider access conditions may change and failures are shown rather than bypassed.

Browse delivery: ASF's public catalog currently points to datapool.asf.alaska.edu/BROWSE/{SA,SB,SC,SD}/<Sentinel-1 product>.jpg. A disabled-by-default local relay follows only validated redirects to sentinel1.asf.alaska.edu and the specifically verified ASF CloudFront delivery distribution and image-bucket path. Provider-issued short-lived delivery query strings remain internal to one request; they are not credentials embedded in source code, stored, logged, or returned to the browser. Unknown redirect hosts/paths fail. No general-purpose URL proxy is exposed. The server requires UCAS_PUBLIC_SAR_ENABLED=1 as well as the explicit browser opt-in and Preview action.

No new third-party software dependency is added by the SAR feature. Existing runtime/development versions are exact-pinned in package.json and pnpm-lock.yaml. Existing software notices remain at /worldview-software-notices.txt, /offline-library-notices.txt, and /worldview-local-layers-notices.txt. Data terms above are separate from those software licenses.

Interpretation: these are actual provider browse images, not generated/synthetic evidence, not live video, not calibrated full-resolution data, not verified ground truth, and not georeferenced raster overlays. The local map renders catalog footprints only. Speckle, viewing geometry, shadow/layover, polarization, processing, acquisition scheduling, and archive latency affect interpretation. No aircraft command or autonomous decision path is connected.
