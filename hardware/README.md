# Hardware workstream

Start with `inventory-template.csv` and reviewed requirements, then add interfaces, revision records, source design files, and supplier references. The CSV is an empty template, not a bill of materials or procurement recommendation. A non-authoritative [reference multicopter configuration](../docs/reference-multicopter-configuration.md) and [Holybro Pixhawk 6C hardware reference](reference-multicopter.json) provide a quadrotor baseline only; they do not select the owner’s hardware or establish compatibility evidence.

Track airframe, propulsion, power, flight controller, sensors, communications, and ground equipment as applicable after scope review. Record compatibility, power/interface budgets, mass, and test evidence for actual selected parts. No physical design or reference configuration has been validated.
