# UCAS patent package — source archive

This directory contains the extracted files from `UCAS_Patent_Package_UPDATED_2026-10-06.zip`, added as project source material on 2026-10-16.

## Contents

- `10_COMPLETE_REVISED_PACKAGE_FOR_REVIEW.pdf`: consolidated review package.
- `draft_documents/`: revised utility specification/claims, provisional draft, ADS worksheet, IDS/prior-art draft, filing checklist, claim strategy, error-resolution log, and drawing QA.
- `drawings/04_REVISED_PATENT_DRAWINGS.pdf`: eight-sheet monochrome patent-style drawing set.
- `source_materials/`: base package, original drawing sheets, and latest drawing reference image.

## Important status

These files are explicitly **draft legal materials for attorney review**, not a filed application, patentability opinion, validated system specification, flight authorization, or engineering test evidence. Factual/legal placeholders remain in the package, including inventors, applicant/assignee, priority, government interest, disclosure history, and filing data. The preliminary prior-art list is not a complete search or legal conclusion.

The extracted originals are retained for provenance. The project’s engineering interpretation is in [`docs/patent-derived-specifications.md`](../../docs/patent-derived-specifications.md), which labels each item as proposed, derived, or pending review. Do not edit the originals in place; add dated notes or a new package if the source package changes.

The package includes references to lawful uses such as flight research, environmental monitoring, search and rescue, communications relay, and logistics. This repository does not add weapon targeting, weapon release, or lethal-engagement functionality.
