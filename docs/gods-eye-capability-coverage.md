# God's Eye View capability coverage

**Review basis:** upstream `gods-eye-view` at [`7be5937`](https://github.com/bilawalsidhu/gods-eye-view/tree/7be5937fc3e3b10cdfa8d3f833536167268768ad), the checked-out SignalWarden PR18 source, README, and the current WorldView UI. This is an integration inventory, not a claim that SignalWarden imported the upstream application or its assets.

## Status vocabulary

- **Implemented:** the behavior is present in this checkout and bounded by local code/tests. “Implemented” does not mean upstream parity or production live coverage.
- **Partial:** a local primitive or UI exists, but a live source, full operator workflow, provider terms, or upstream-equivalent behavior is absent.
- **Manual/imported:** the UI accepts a user-authorized, validated local pack; no provider adapter or authenticity claim is implied.
- **Deferred/unavailable:** no current SignalWarden implementation; do not describe it as available.

It has no Cesium, imagery, terrain, Google 3D Tiles or navigation-map accuracy. |
| Global context / geographic focus | Global place/entity search, geo URI search, city presets and camera handoff | **Implemented bounded UI.** Local city presets, decimal coordinates and `geo:` search move the schematic globe. Global context saves/restores the local view and enables all context layers. It is not a global geocoder or upstream camera service. |
| Detection HUD | Detection/overlay presentation and operator HUD controls | **Implemented as presentation state.** The detection toggle changes contact emphasis/labels; it is not a sensor detector, classifier, alert engine or proof of detection. |

## Source boundary

The implemented live-source slice is deliberately limited to **USGS earthquakes, NOAA/NWS `weather.gov` forecasts and `adsb.lol` aircraft points**, each manually requested with network opt-in and source/freshness disclosure. EONET live reads remain disabled for license review. The synthetic demo records and user-authorized observation packs are separate from those live adapters. Vessels, cameras, ALPR locations and aggregate traffic have named synthetic/importable layers. Other imported layer names may be queried but have no dedicated UI toggle or provider adapter. Restricted upstream cable/flood datasets remain excluded.

**API credentials:** PR18 does not configure or use provider credentials for WorldView. Any future environment-variable names are proposals only until an adapter, deployment configuration, terms review and tests exist. Never describe a key as configured merely because an upstream provider requires one.

**Safety boundary:** every marker is an observation or presentation object. WorldView remains read-only: it must not send flight commands, change an autopilot mode, alter a mission, bypass signing/freshness/replay/RBAC, or add Lattice deployment behavior.

## Provenance notes

Upstream qualifiers survive integration: feeds may be live or refreshed, traffic may be simulated on real roads, camera poses may be coarse estimates, and a pin/line/cone/model-rendered object is not proof of an event or location. Future implementations must be original SignalWarden code, preserve provider notices, and receive a separate license/provenance review.
